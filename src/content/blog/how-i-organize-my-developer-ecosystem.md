## Names Need Jobs

An ecosystem gets confusing when every name tries to do every job. I split the work into surfaces with clear responsibilities.

ZPMLabber is the maintainer identity. ZPMLabs is the broader umbrella. Community SDKs is for external API wrappers. ZPM Packages is for reusable tools, plugins, and adapters that do not belong to one API ecosystem.

## Why This Helps

The split makes discovery easier. Someone looking for a service wrapper can start with Community SDKs. Someone looking for framework utilities or tooling can start with ZPM Packages. The blog connects the reasoning behind both.
